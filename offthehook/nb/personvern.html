Personvern

Gjelder fra 25. november 2026

Kort fortalt: Off the Hook samler ikke inn personopplysninger. Ingen kontoer, ingen analyse, ingen reklame og ingen sporing. Fremgangen og innstillingene blir på iPhonen din. Topplisten går via Apples Game Center, og kjøp via App Store.

Hvem vi er

Off the Hook er et spill for iPhone laget av Knudegaard Apps (org.nr. 938 917 523), Eineråsen 21D, 4790 Lillesand. «Vi» betyr Knudegaard Apps. Du når oss via kontaktskjemaet.

Hva vi samler inn

Ingenting. Off the Hook har ingen brukerkontoer og ingen servere som tar imot data om deg. Spillet inneholder ingen analyse-, reklame- eller sporingsverktøy, og vi sporer deg ikke på tvers av apper eller nettsider.

Lagret på iPhonen

Beste distanse, perler, fisker, oppgraderinger, daglige oppdrag, rekken for daglig gave og lydinnstillinger lagres bare i appens private lagring på enheten. De blir med i den vanlige sikkerhetskopien til iCloud eller datamaskinen, som Apple står for, og slettes hvis du sletter appen.

Game Center

Er du logget inn i Game Center, sender spillet beste distanse til topplisten og fremgang på prestasjoner til Apple. Andre spillere kan se Game Center-navnet og poengsummen din på topplisten. Innloggingen håndteres av iOS, og Apples personvernerklæring gjelder. Du kan slå av Game Center under Innstillinger → Game Center.

Kjøp

Fullversjonen er et engangskjøp som håndteres helt av Apple gjennom App Store. Vi ser aldri navn, e-postadresse eller betalingsinformasjon. Off the Hook sjekker bare med Apple, på enheten din, om fullversjonen er aktiv.

Barn

Off the Hook passer for alle aldre og samler ikke inn data fra noen, heller ikke barn. Apples foreldrekontroll (Skjermtid) kan begrense kjøp og Game Center.

Dine rettigheter

Vi har ingen personopplysninger om deg, så det finnes ingenting å gi innsyn i, rette eller slette. Du fjerner alt Off the Hook lagrer ved å slette appen. Ta gjerne kontakt med spørsmål, og du kan klage til Datatilsynet.

Endringer

Endrer vi erklæringen, oppdaterer vi denne siden og datoen over. Skulle en endring bety at data om deg forlater enheten, spør vi om lov i appen først.
